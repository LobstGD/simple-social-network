# Simple Social Network

🌐 **Live Demo:** [http://85.193.84.115]

A full-stack social networking application built with **Spring Boot** for the backend and **React + Vite** for the frontend. This project demonstrates a small-scale social network with core features like authentication, post management, donations, and private messaging.

---

## Features

### Backend (Spring Boot)
- User authentication and authorization (JWT-based)
- Full CRUD operations for posts:
  - Create, read, update, delete posts
- User profile management and personal home pages
- Secure API endpoints with role-based access
- Private chat system between users
- Donation system integration with **YooMoney** and **PayPal**

### Frontend (React + Vite)
- Responsive user interface
- User registration and login
- Home feed with posts from followed users
- Personal profile pages with post management
- Private chat interface
- Donation forms and payment integration
- Routing handled with **React Router**

---

## Technologies Used
- **Backend**: Java, Spring Boot, Spring Security, PostgreSQL
- **Frontend**: React, Vite, Tailwind CSS (optional styling), React Router
- **Database**: PostgreSQL
- **Payment Integration**: YooMoney, PayPal
- **Containerization**: Docker, Docker Compose
- **Server**: Nginx (for frontend static files)

---

Usage

Register a new account or login with existing credentials.

Create posts, like, edit, or delete them.

Browse the home feed and visit other users’ profiles.

Send private messages to other users.

Donate to users via YooMoney or PayPal.
